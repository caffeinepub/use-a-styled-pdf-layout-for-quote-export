# PDF Export Pre-Deploy Verification Checklist

This document outlines the manual verification procedure that must be completed before marking a deployment as verified.

## Purpose

Ensure that PDF export functionality works correctly in the deployed build for both Quote Summary and Analysis views.

## Prerequisites

- The application must be deployed and accessible via its URL
- Test with a fresh browser session (or use incognito/private mode)
- Perform a hard refresh (Ctrl+Shift+R or Cmd+Shift+R) to ensure no cached assets

## Verification Steps

### 1. Quote Summary PDF Export

1. Navigate to the Quote Generator tab
2. Add at least 3 items to the quote with varying quantities and durations
3. Fill in all required header fields (Client Name, Project Name, Account Manager, Project Duration)
4. Click "Generate Quote" button
5. In the Quote Summary view, click the "Export to PDF" button
6. **Expected Result**: A PDF file should download immediately with the filename format `quote_[clientname]_[timestamp].pdf`
7. Open the downloaded PDF and verify:
   - All header information is present and correct
   - All quote items are displayed in a table
   - Quantities, durations, and totals are accurate
   - Grand total is displayed prominently
   - Footer shows page numbers and "Generated by QuoteGen Application"
